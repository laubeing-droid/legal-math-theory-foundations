# 法律数学理论基础
## legal-math-theory-foundations

先把法律讲清楚，再讨论哪些内容能够形式化，以及数学如何约束实现。这个仓库保存法理学、中国法律运行理论、形式化论证和研究路线；具体数学定义、推导与证明放在 [legal-math-modeling](https://github.com/laubeing-droid/legal-math-modeling)。

本仓是私有研究工作区。当前完成的是组织起步，不是理论统稿或法律核查完成。原始稿件和资料尚须逐件接收、阅读、核查；不能用本页替代正式理论。

## 七步主线

法理学统稿＋中国法律运行理论 → 中国法律运行总图＋资产盘点 → 法律工作流程规格＋库存对应 → 统一数学理论与补正 → 中国部门法特化 → 法律工程实现与接入 → 整体验收。

法理学统稿与中国法律运行理论可以并行准备，随后互相校正。部门法实例从前期就用于检验，第五步再系统建设特化内容。步骤是工作安排，不是把法律运行说成单向流水线。

| 对象 | 在这里做什么 | 不在这里冒称什么 |

## 文档与任务如何同步

有结论就更新对应正文，并在任务中说明改了哪里、依据是什么、如何检查。不要让一个决定在 README、任务描述和理论正文里各有一种版本。看板四列采用“待做／在做／待检查／完成”；创建卡片不等于完成任务，移到完成前须留下可核的产出和检查结果。

不上传案件私密材料、凭据或原始私人聊天。研究稿、盘点报告等新交付文件以 `YYYYMMDD_` 开头；根目录 `README.md` 保留 GitHub 的导航文件名。本次初始化日期：2026-11-13。
