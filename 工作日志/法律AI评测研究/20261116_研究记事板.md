## 一、目标与要求沿革

### 当前目标
从可合法获取的评测题、输入、标准答案、评分规则及必要附件中，逐条识别：
1. 它实际要求法律 AI 做什么；
2. 它暴露哪些现实法律需求、制度条件、程序要求和翻车风险；
3. 标准答案、评分及任务假设本身有什么局限；
4. 既有理论覆盖了什么、连接不足在哪里、什么确实需要补；
5. 如何据此提出原七步路线的细化、先后与优先级建议。

不是做品牌排名，不以分数代替法律判断，不为现有理论寻找单向佐证，也不预设所有缺口都属于工程。

## 二、范围与计量口径

初始集合：LegalBench、CaseLaw v2、Vals.ai、Harvey BigLaw Bench、Harvey LAB、LawBench、newtouch-LawBench、CAIL、PLawBench、J1-Bench。
Vals.ai 是平台入口，不自动当成独立题库；CAIL 按年份和赛道分别登记。集合名称相近不推定版本相同。

每个版本分别登记：官方来源、取得时间、版本/提交、许可与可用范围、文件清单、记录数量、附件关系、重复关系、缺件及解析错误。
哈希可辅助确认字节，不是语义审读或法律正确的证明，不能用指纹问题卡住内容研究。

状态严格拆分：
- **可定位**：找到官方来源或文档。
- **已取得**：实际文件可读；不能只看下载成功回执。
- **已解析**：字段/页数/记录数有可复核清单。
- **已语义审读**：逐项查看任务、输入、金标/评分及明确范围内附件，并写出具体问题证据。
- **已复核**：独立核对相应证据；金标中的法律断言并不因读过就算已核法源。
- **未取得/受限/未读/重复/异常**：明确登记，不能从分母中悄悄消失。

“全量”只能指已定义版本和范围；发现新版本要追加差异范围，不回填旧完成率。

## 三、施工步骤与逐步验收

| 步骤 | 动作 | 通过条件 |
|---|---|---|
| A 范围建账 | 官方来源、版本、许可、受限状况、题目/附件清单 | 每一来源有状态；不明写 UNKNOWN |
| B 获取及解析 | 保存原件，解析记录和附件，记录错误/重复 | 清单可重算，原件可回查；解析失败单列 |
| C 逐项审读 | 每题记录现实任务、证据、问题、限制、疑点 | 每个已读 ID 有具体内容记录；抽样不冒充全读 |
| D 穷举问题 | 一题可产生多问题；无新问题也留已读记录 | 题目与问题双向链接；遗漏与空项可查 |
| E 递归分类 | 具体问题归并、分层，再以反例拆分或修订 | 每次结构变化有理由和保留的旧 ID |
| F 横向归纳 | 跨集合对应、独立性、频次、严重性、制度边界 | 多集合频次不混同真实社会发生率 |
| G 理论对照 | 对照一般法理、中国运行、形式化及现有工程 | 已覆盖/连接不足/候选缺口/待核/实现未知分开 |
| H 交付与抽查 | 总报告、明细、分类理由、日志、路线建议 | 可从任一结论回查题项，也可从题项查分类 |
| I 验收后收尾 | 接收反馈、补漏，确定留存与缓存处置 | 用户确认成果；任何批量删除另获批准 |

## 四、逐项记录最小字段

`item_id、dataset、version、split、source_locator、attachment_ids、read_scope、read_status、reviewer、read_time、task_goal、legal_context、procedure_stage、role、known_and_missing_facts、required_actions、expected_output、gold_claim、rubric_claim、observed_problem_ids、failure_modes、practical_conditions、evidence_locators、uncertainty、theory_mapping、next_action`

不要求每题编造新问题。没有发现独特问题可以关联已有问题并说明为何相同；无法判断写未决。
公开材料只发表允许公开的定位、统计和概述；完整题目、账户资料、私人材料不放本目录。

## 五、归纳与自查办法

1. 先保留具体问题，再归类，不能先定几个抽象标签把全部题硬塞进去。
2. 每次合并写明共同机制、差异为何不影响归类；拆分写明被原类别掩盖的法律/程序条件。
3. 保留反例、少数情况和争议；“未发现”只限已读范围。
4. 区分记忆、理解、应用的任务要求；不能只凭答对或运行轨迹证明模型内部认知机制。
5. 区分律师已给清晰目标与普通当事人的澄清需求；不能把 AI 设为无限代办者。
6. 检查阶段、期限、已知信息、策略性延后、新事实与补救，避免把所有未完成都等同能力失败。
7. 确定性程序可以降低特定成本和错误，但硬编码不自动等于法律正确、公平或安全。
8. 把原题、金标、评分规则、独立法律依据、研究者推断分栏，避免循环证明。
9. 每批结束核对范围数 = 已读 + 未读 + 明确排除/重复等可解释状态；同一条不能隐性重复计数。
10. 抽查双向路径：随机题目 → 原件/附件 → 问题 → 分类理由；随机结论 → 所有支撑题目 → 反例。
11. 总协调续工先读本页、Issue 最新记录及实际分片账；核对最新要求和版本，再从断点接续，不依据旧摘要重做。
